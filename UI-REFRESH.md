# Smart Stock AI — UI Refresh

## Visual direction
- Premium, balanced-density SaaS interface.
- Preserve the existing teal + deep navy brand identity.
- Keep Arabic RTL and English LTR, plus light/dark themes.
- Use consistent rounded controls, restrained borders, subtle elevation, and semantic status colors.

## Navigation and shell
- Wider desktop sidebar with collapsible navigation groups.
- Active route has a clear teal-accented state; collapsed icons expose their page name as a tooltip.
- Header includes global page navigation search (`Ctrl/Cmd + K`), quick transaction entry, connectivity state, language, theme, notifications, and user menu.
- Mobile bottom navigation prioritizes overview, sales (when enabled), inventory, and products, with the rest in the drawer.

## Dashboard
- KPI cards use a responsive grid and semantic icon treatments.
- Daily shortcuts are visually distinct and responsive.
- Charts, alerts, recent documents, and warehouse summaries use consistent panel surfaces.
- Existing data sources and calculations are preserved; this refresh changes presentation, not business logic.

## Shared components
- Standardized button and form-control radii, focus rings, hover/pressed states, and disabled states.
- Page headings and panels have consistent hierarchy and spacing.
- Shared data tables have clearer headers, row spacing, hover feedback, and horizontal overflow support.
